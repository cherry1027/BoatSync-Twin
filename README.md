BoatSync Twin is an offline-first edge digital twin prototype for connected marine systems. It demonstrates how remote boat commands can be queued during network outages, executed after reconnection, and synchronized across cloud, edge, and physical-device states.
The main demonstration sends an AC = ON command while the boat is offline. The command is stored in an asynchronous queue while an onboard user manually sets the AC to OFF. When connectivity returns, the system exchanges state versions, detects the conflict, applies the selected resolution policy, and converges all three states.
The prototype includes a vessel dashboard, remote command center, conflict-resolution lab, synchronization timeline, network failure simulator, and digital twin state inspector. Network presets simulate stable, intermittent, high-latency, packet-loss, offline, and reconnecting conditions using deterministic synthetic data.
